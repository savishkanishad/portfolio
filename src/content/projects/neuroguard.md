### Project Overview
NeuroGuard was built to solve the critical issue of road safety. Its computer vision engine monitors facial landmarks to detect signs of drowsiness with 95% detection accuracy at 30 FPS, while the web dashboard supports remote safety tracking and security auditing.

### Key Features
*   **Real-time Detection:** Processes webcam input at 30 FPS and achieved 95% detection accuracy during testing.
*   **Alert System:** Triggers an alarm when distraction levels exceed the threshold.
*   **Secure Logs:** Uses MySQL to store safety events for dashboard analytics and later review.
*   **Security Auditing:** Includes security-focused review of authentication, access control, and dashboard data handling.
